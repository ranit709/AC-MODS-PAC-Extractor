# ⚡ AC-MODS PAC EXTRACTOR
A high-performance Unisoc/SPD PAC firmware extraction tool optimized for Termux.

## 📌 Features
- Extracts 100% of internal partitions and images without file filtering.
- Uses chunk-buffered reading for massive files without freezing Termux.
- Custom ANSI UI with fixed Telegram branding.

## 💻 Installation & Usage
```bash
git clone https://github.com/ranit709/AC-MODS-PAC-Extractor.git
cd AC-MODS-PAC-Extractor
python ac_mods_extractor.py
```
